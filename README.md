Дүкен кассасы
Дүкен кассасының жұмысын модельдеу. Бағдарлама тауарларды каталогқа қосады, сатады, чек шығарады және төлем жасайды.

Қолданылған кластар
* Product – тауар туралы ақпарат.
* DiscountProduct – жеңілдікпен сатылатын тауар.
* CashRegister – касса.
* Receipt – чек.
* PaymentInfo – төлем туралы ақпарат.

Орындалған талаптар
* Статикалық мүшелер
* Дос функция
* Кірістірілген класс
* Объектілер жиымы
* Композиция
* Агрегация
* Мұрагерлік
